対象文書: $ARGUMENTS

以下の手順で進めてください。

1. `$ARGUMENTS` で指定された文書を読み込む。パスが省略された場合はユーザーに確認する。
2. 未決事項・不明点のリストを取得する。
   - 文書内に「未決事項」「不明点」「TODO」などの見出しでリスト化されたセクションがあれば、それを優先的に読み取る。
   - そのようなセクションがない場合は、文書全体を精査し、未決事項・不明点(TODO、要検討、TBD、曖昧な記述、複数解釈が可能な箇所、欠落している判断など)を洗い出してリスト化する。
3. リストアップした項目を、文書中の登場順(または依存関係がある場合はそれを優先)に、**一つずつ**次のように解決する:
   - `AskUserQuestion` ツールを使って質問する。
   - 選択肢を2〜4個提示し、あなたが最も妥当と考える案を**先頭**に置き、ラベル末尾に「(推奨)」と付ける。
   - 各選択肢の description には、選んだ場合の影響やトレードオフを簡潔に書く。
   - 一度に複数の未決事項をまとめて質問しない。必ず1問ずつ確定させてから次に進む。
4. 各質問への回答が得られたら、その場で文書を編集する。
   - 決定内容は、関連する本文中の見出し・箇所に記載する(該当箇所がなければ適切な見出しを作成して記載する)。
   - 未決事項・不明点リストからは、確定した項目を削除する。打消し線を付けたり、別枠の「決定事項」セクションとして残したりはしない。
5. 全項目が確定したら、変更点の要約を簡潔に報告する。

注意:
- 質問の前に、あなたの推奨と理由を無闇に長く説明しない。AskUserQuestionのdescriptionに集約する。
- 文書の実体を編集する際は、このリポジトリの方針(CLAUDE.md)に従い、シンボリックリンク先ではなくリポジトリ内のファイルを直接編集する。
- 新規ファイルを作成した場合は `links.json` への追加要否を確認する。
