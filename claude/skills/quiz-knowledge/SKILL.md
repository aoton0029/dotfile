# 想起で定着させる

カードを読み返しても定着はしない。**カードを閉じた状態で説明させる**のがこのスキルの役目。
副産物として、説明できなかった箇所はカードが薄い箇所でもある（→ `deepen-knowledge`）。

## 前提を読む

- [../capture-knowledge/references/vault.md](../capture-knowledge/references/vault.md)

## 起動のされ方

- `/quiz-knowledge` — 引数なし。出題範囲はこちらで選ぶ
- `/quiz-knowledge <テーマorタグ>` — 範囲指定（例: `concurrency`）
- 「カードから出題して」等の依頼文

## 手順

### 1. 出題範囲を決める

指定があればそのテーマ／タグ。無ければ `knowledge/` から選ぶ:

- `updated` が古いもの（忘れている頃合い）
- `confidence: verified` のもの（検証済みの知識ほど定着させる価値がある）

**1回3〜5問。それ以上出さない。**

### 2. 出題する

1問ずつ出す。まとめて出さず、回答を受けてから次へ進む。カードの本文は**見せない**。
以下を混ぜる:

- **説明問題** — 「なぜそう動くのか」を自分の言葉で言わせる（根本メカニズムから）
- **因果問題** — 「Xを変えると何がどうなるか」（構成要素と因果関係から）
- **応用問題** — カードに書いていない状況を出し、原理から判断させる
- **区別問題** — 似た概念との違いを言わせる（他の概念とのつながりから）

用語の穴埋めや暗記問題は出さない。原理を運用できるかを見る。

### 3. 採点する

回答ごとに、**カードの記述と突き合わせて**評価する:

- 合っている点を先に、短く
- 抜けている因果・混同している概念を名指しで
- カードの該当箇所を `[[ノート名]]` の該当節として示す

回答がカードより正確な場合がある。そのときは**カードの方が古い/薄い**と指摘する。

### 4. 締め

- 説明できなかったカードを列挙し、`deepen-knowledge` の対象として提示する
- カードの記述自体に誤り・不足が見つかったものは、それも分けて挙げる

このスキルではカードを書き換えない。修正は `deepen-knowledge` に渡す。
